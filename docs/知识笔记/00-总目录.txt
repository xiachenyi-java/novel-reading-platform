【这份文件是什么】
  Java 后端的知识地图。只讲原理，不涉及任何具体项目。

【四个目录的分工 ★ 别搞混】
  docs/知识笔记/   ← 你正在看的：原理、比喻、面试题      "是什么"
  docs/项目笔记/   ← 现状盘点、待办清单                  "做到哪了"
  docs/实战笔记/   ★ 2026-10-06 新增：                   "我怎么做的"
                     怎么做 / 怎么验证 / 踩了什么坑
  docs/面试题库/   ★ 2026-10-06 新增：                   "被追问时怎么答"
                     按分类装，每题带「加分点 / 陷阱 / 追问链」

  编号一一对应：
    知识笔记/03-认证授权.txt          讲 JWT、Session、RBAC 的原理
    项目笔记/03-认证授权.txt          讲项目里认证模块做到哪了
    实战笔记/05-缓存三大问题实战.txt   讲这次改造的完整过程和实测数据

【怎么用】
  · 学习时：只看这个目录，按大类推进
  · 写代码时：查对应的知识笔记，找原理和坑
  · 做完一次实验/改完一个 bug 后：往实战笔记里追加一份复盘
  · 面试前：看面试题库 —— ★ 不是看知识笔记，那份是给学习用的，
            面试要的是"怎么组织语言、被追问怎么接"
