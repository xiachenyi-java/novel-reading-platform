  一、技术栈与启动命令
################################################################################

  Vue            3.5.13        （Composition API + <script setup>）
  Element Plus   2.8.8         （+ @element-plus/icons-vue 2.3.1，main.js 里全局注册了所有图标）

  axios          1.7.7
  pinia          2.2.6         ★ 装了也注册了，但**全项目没有用任何 store**，状态都走 composables/
  Vite           5.4.11        Node >= 18

  包管理器：**npm**（有 package-lock.json，README 也写的 npm）
            ⚠ node_modules/ 里有 .pnpm/ 和 .ignored/ 残留目录，别被误导，用 npm 就行

  ## 启动（在他机器上直接给这两条，别让他自己拼）
    cd novel-frontend
    npm run dev          →  http://localhost:5173
    npm run build        →  产物在 dist/

  ## 后端地址怎么配（vite.config.js:13）
    默认 http://localhost:8080（IDEA 里跑的后端）
    换地址：VITE_API_TARGET=http://localhost:8081 npm run dev   （Docker 里的后端）
    ★ 代理规则：浏览器请求 /api/xxx → 转发到 {后端}/xxx，**rewrite 会去掉 /api 前缀**
      所以 api 文件里写 '/novels'，实际打到后端的是 {后端}/novels
    ★ 这个代理只在 dev 生效。生产由 Nginx 反代 /api，不走这里。

  ## 起不来的常见原因
    · 页面一片"暂无小说" → 多半是后端没起（vite 日志里会有 proxy error ECONNREFUSED）
    · 样式改了不生效 → 先 Ctrl+Shift+R 硬刷新，别急着改代码
    · Redis 容器叫 demo2-redis（docker ps 可查），后端依赖它

################################################################################
  五、样式规范（硬性，别破）
################################################################################

  1. 颜色/字号/间距/圆角一律用 tokens.css 的变量，**不写硬编码色值**
  2. 间距用 4 的倍数；字号只用那 7 档
  3. 样式**就近放**（页面自己的 <style scoped>），不搞全局大 CSS
     唯一例外：设计变量（tokens.css）必须全局
  4. **不写行内 style**，除非是动态计算的值
     ⚠ 现存 21 处行内 style，其中 NovelListView.vue:95 和 :152 的 padding:60px 0
       会盖掉 CSS 的左右 24px，导致"加载中→有数据"切换时内容横向跳（已知问题，未修）
  5. 三态齐全：**加载中 / 空数据 / 报错** 三个都要有
     ★ 这是最能区分"学生作业"和"能用的产品"的地方
  6. 响应式至少保证 375px（手机）和 1440px（桌面）不崩
     ⚠ 目前零媒体查询的页面：NovelDetailView / ChapterReadView / WriteNovel / SiteFooter / App.vue
       （static/ 下 5 个也没有，但它们继承 StaticPageLayout 的 640px 规则，不算问题）
       其中前三个有 padding:16px 40px 固定值，窄屏会挤
  7. 过渡 150~200ms（用 --t-fast / --t-base），不搞花哨动画
  8. 中文注释写清"这块在干嘛"；组件名大驼峰，文件名跟组件名一致

################################################################################
  八、全局约定（改动前必看）
################################################################################

  ## Token 怎么走（api/index.js）
    · 请求拦截：从 localStorage 读 token → 塞 Authorization: Bearer <token>
    · ★ el-upload 那种不走 axios 实例的请求，要自己带 header
      （见 WriteNovel.vue:46 的 :headers="uploadHeaders"）
    · localStorage 存的 key：token / refreshToken / username / role

  ## 401 vs 403（★ 别搞混）
    401 未登录/token 失效 → 清凭证；**本来登录着**（hadToken）才跳登录页并带 redirect，
                            本来就是游客则不跳，交给页面自己处理
    403 已登录但无权限   → **不清凭证、不跳登录页**，直接 reject 让调用方提示
    ★ 把 403 当 401 处理 → 管理员权限不足会被误踢下线

  ## 登录态怎么读
    · 组件里统一用 useAuth()：isLogin / isAdmin / username
    · 退出用 useAuth().logout() + router.push('/login')，**不要** localStorage.clear()
      （定向删除，避免以后加了主题偏好等 key 被一起清掉）
    · requireLogin('收藏') → 未登录时弹 ElMessageBox 确认框，返回 boolean

  ## ⚠ refreshToken 现状
    登录时存了 refreshToken（LoginView.vue:209），但**全项目没有任何续期逻辑**，
    只在 401/退出时被删掉。属于"存了没用"，别以为 token 失效会自动续。

  ## 错误提示统一用
    ElMessage.error / warning / success（Element Plus），不用 alert()
    ★ 目前有 2 处**静默失败**（控制台有 error、界面无提示）：
      NovelListView.vue:200  分类加载失败
      ChapterReadView.vue:64 章节列表失败
